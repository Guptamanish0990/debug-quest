# 🐞 Debug Quest

🔗 **Live Website:** https://debugquest.netlify.app/

Debug Quest is an **interactive coding practice and interview preparation platform** designed to help developers improve their debugging skills, logical thinking, and frontend interview readiness through real-world challenges. Whether you're preparing for technical interviews, building problem-solving skills, or simply enjoying the thrill of debugging, Debug Quest offers a comprehensive learning experience with gamification, progress tracking, and expert-level challenges.

---

## 🚀 What is Debug Quest?

Debug Quest is a **gamified learning platform** where users solve buggy code challenges, track progress, build streaks, and prepare for frontend interviews — all in one place.

**Perfect for:**
- 🎓 **Beginners** learning programming fundamentals and building confidence
- 💻 **Intermediate developers** sharpening debugging and problem-solving skills
- 🚀 **Frontend developers** preparing for technical interviews at top companies
- 🎯 **Anyone** looking to master debugging through hands-on practice
- 👨‍💼 **Interview candidates** wanting to ace technical rounds with real-world scenarios

**Why Debug Quest?**
- Learn by doing, not just reading
- Get instant feedback on your solutions
- Build consistency with daily challenges and streaks
- Prepare comprehensively with 200+ interview questions
- Track your growth with detailed progress analytics

## 🚀 Getting Started

### Prerequisites
- **Node.js** (v14 or higher) - [Download here](https://nodejs.org/)
- **npm** or **yarn** - Comes with Node.js
- **Git** - For version control

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/debugquest.git

# Navigate to project directory
cd debugquest

# Install dependencies
npm install

# Start development server
npm start
```

The application will run on `http://localhost:3000`

### Build for Production

```bash
# Create optimized production build
npm run build

# The build folder will contain optimized static files
# ready for deployment
```

## 🎯 How to Use Debug Quest

### For Debugging Practice:
1. **Choose your language** - Select from HTML, CSS, JS, React, etc.
2. **Pick difficulty** - Start with Easy or challenge yourself with Hard
3. **Read the problem** - Understand what's wrong with the code
4. **Debug & fix** - Identify and correct the bugs
5. **Submit solution** - Get instant feedback on your fix
6. **Earn XP** - Collect experience points and maintain your streak
7. **Review explanation** - Learn from detailed solutions

### For Interview Preparation:
1. **Browse questions** - Explore 200+ interview questions
2. **Filter by category** - Focus on specific topics you need
3. **Practice mode** - Take your time learning each question
4. **Mock interview** - Simulate real interview conditions
5. **Bookmark favorites** - Save important questions for review
6. **Track progress** - Mark questions as completed
7. **Review regularly** - Come back and reinforce your learning
